# 📊 SQL-Based Dashboards

## 📌 Overview
Created a collection of SQL-based Power BI dashboards focused on sales analytics, gaming analytics, quick-commerce insights, and electric vehicle business intelligence through interactive visualizations.

These dashboards demonstrate SQL data analysis, KPI tracking, trend analysis, customer insights, product performance, and data storytelling techniques using SQL, Power BI, and DAX.

---

## 📊 Dashboards Included

### ☕ Supreme Cafe Dashboard
An interactive cafe analytics dashboard designed to monitor sales performance, orders, revenue, customer insights, beverage categories, and store performance through dynamic visualizations.

### 🎮 GTA 6 Dashboard
A gaming analytics dashboard focused on GTA 6-related data, performance metrics, trends, comparisons, and interactive gaming insights.

### 🛵 Zepto Dashboard
A quick-commerce analytics dashboard developed to analyze sales performance, products, customers, categories, and business trends through interactive reporting.

### 🚗 TATA EV Cars Dashboard
An electric vehicle analytics dashboard focused on EV sales, car models, customer segments, regional performance, and year-wise sales insights.

## 🎯 Purpose
The objective of this project collection is to transform raw datasets into meaningful business insights using SQL for data analysis and Power BI for interactive dashboard development.

These dashboards demonstrate how SQL and Power BI can be combined to analyze business trends, monitor KPIs, understand customer and product performance, and support data-driven decision-making.
