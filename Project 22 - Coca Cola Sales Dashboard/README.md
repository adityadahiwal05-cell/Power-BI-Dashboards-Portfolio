# 🥤 Coca-Cola Sales Dashboard

## 📌 Overview
Created an interactive Coca-Cola Sales Dashboard in Power BI to analyze sales performance, revenue trends, regional distribution, and brand-wise insights through dynamic visualizations.

The dashboard helps users monitor sales growth, identify top-performing beverage categories, compare regional performance, and gain meaningful business insights for data-driven decision-making.

---

## 🚀 Dashboard Highlights
- Total Sales & Revenue KPIs  
- Regional Sales Performance Analysis  
- Brand-wise Sales Insights  
- Beverage Category Performance Tracking  
- Monthly & Yearly Sales Trend Analysis  
- Profit & Revenue Monitoring  
- State-wise Sales Visualization

## 🎯 Purpose
The objective of this project is to transform Coca-Cola sales data into meaningful business insights using interactive dashboards and analytical reporting techniques.

This dashboard helps businesses and analysts:
- Analyze overall sales performance  
- Monitor regional sales growth  
- Identify top-performing beverage brands  
- Track revenue and profit trends  
- Support strategic business decisions through data visualization
