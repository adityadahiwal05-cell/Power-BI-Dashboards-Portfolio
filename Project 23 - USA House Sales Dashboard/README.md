# 🏠 USA House Sales Dashboard

## 📌 Overview
Created an interactive USA House Sales Dashboard in Power BI to analyze house sales performance, pricing trends, regional sales distribution, and customer purchasing insights through dynamic visualizations.

The dashboard helps users explore sales trends, identify high-performing regions, compare property categories, and gain valuable business insights for better decision-making in the real estate sector.

---

## 🚀 Dashboard Highlights
- Total Sales & Revenue KPIs  
- Regional Sales Analysis  
- Property Price Trend Insights  
- Customer Purchase Behavior Monitoring  
- State-wise Sales Visualization  
- Property Category Performance Tracking  
- Monthly & Yearly Sales Analysis

## 🎯 Purpose
The objective of this project is to transform USA house sales data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze sales performance, monitor regional growth, identify top-performing property categories, and support strategic business decisions in the real estate market.
