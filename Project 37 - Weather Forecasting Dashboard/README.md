# 🤖 AI Generated Dashboard – Weather Forecasting Dashboard

## 📌 Overview
Created an AI-generated **Weather Forecasting Dashboard** in Power BI to analyze weather conditions, temperature trends, humidity levels, air quality, wind speed, and forecasting insights through interactive and modern visualizations.

This dashboard was designed with the help of ChatGPT to transform raw weather data into meaningful environmental insights using advanced reporting techniques and smart dashboard storytelling.

## 📊 Dashboard Included

### 🌦️ Weather Forecasting Dashboard
An interactive weather analytics dashboard designed to monitor temperature variations, humidity, air quality index, rainfall probability, wind speed, visibility, and weekly forecasting trends through dynamic visualizations.
