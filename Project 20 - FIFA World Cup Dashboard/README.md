# ⚽ FIFA World Cup Dashboard

## 📌 Overview
Created an interactive Sports Analytics Dashboard in Power BI to analyze FIFA World Cup data, team performance, match statistics, player insights, and tournament trends through engaging visualizations.

The dashboard helps users explore football statistics, compare team performances, and gain meaningful insights into World Cup history and tournament analytics.

---

## 🚀 Dashboard Highlights
- Total Matches & Goals KPIs
- Team-wise Performance Analysis
- FIFA World Cup Winners Tracking
- Player & Goal Statistics
- Match Result Insights
- Tournament Trend Analysis
- Country-wise Performance Visualization

## 🎯 Purpose
The objective of this project is to transform FIFA World Cup and football statistics into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze tournament trends, monitor team and player performance, compare match statistics, and support data-driven sports analysis.
