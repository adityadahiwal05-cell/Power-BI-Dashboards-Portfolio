# 👨‍💼 IBM HR Analysis Dashboard

## 📌 Overview
Created an interactive HR Analytics Dashboard in Power BI to analyze employee data, workforce trends, attrition patterns, and organizational performance through dynamic visualizations.

The dashboard helps HR teams and organizations monitor employee insights, improve workforce management, and make data-driven decisions for better employee retention and productivity.

---

## 🚀 Dashboard Highlights
- Employee Count & Attrition KPIs
- Department-wise Workforce Analysis
- Employee Age & Gender Insights
- Salary & Job Role Comparison
- Attrition Trend Monitoring
- Education & Experience Analysis
- Workforce Performance Visualization

## 🎯 Purpose
The objective of this project is to transform HR and employee data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps organizations analyze workforce trends, monitor attrition patterns, understand employee demographics, and support strategic HR decision-making.
