# 🏅 Olympics Dashboard

## 📌 Overview
Created an interactive Sports Analytics Dashboard in Power BI to analyze Olympic games data, athlete performance, medal distribution, country rankings, and historical trends through engaging visualizations.

The dashboard helps users explore Olympic statistics, compare country performances, and gain meaningful insights into sports achievements and event trends.

---

## 🚀 Dashboard Highlights
- Total Medals & Athlete KPIs
- Country-wise Medal Analysis
- Gold, Silver & Bronze Distribution
- Athlete Performance Insights
- Olympic Event Trend Analysis
- Sports Category Comparison
- Historical Olympics Data Visualization

## 🎯 Purpose
The objective of this project is to transform Olympics and sports data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze medal trends, compare athlete and country performances, monitor historical Olympic data, and support data-driven sports analysis.

- Dynamic KPI Cards
