# 📊 Basic Dashboards

## 📌 Overview
Created a collection of beginner-friendly and interactive Power BI dashboards designed to analyze gaming trends, movie performance, sales insights, and business analytics through engaging visualizations.

These dashboards demonstrate the fundamentals of business intelligence, KPI monitoring, trend analysis, and data storytelling using Power BI and modern dashboard design techniques.

---

## 📊 Dashboards Included

### 🎮 Supreme Video Games Dashboard
An interactive gaming analytics dashboard designed to analyze global video game sales, genre performance, publisher insights, and platform-wise sales trends through dynamic visualizations.

#### 🔹 Key Insights
- Global Sales Analysis (1980–2017)
- Genre-wise Video Game Trends
- Top Selling Game Titles
- Publisher Performance Insights
- Platform-wise Sales Comparison
- Interactive Year Filters & Slicers

---

### 🎬 Highest Grossing Supreme Films Dashboard
A movie analytics dashboard created to analyze highest grossing films, domestic revenue trends, studio insights, and movie ranking performance using visual storytelling techniques.

#### 🔹 Key Insights
- Highest Grossing Movies Analysis
- Domestic Gross Revenue Tracking
- Total Studios & Directors KPIs
- Year-wise Movie Insights
- Top 10 Movies Ranking Visualization
- Interactive Movie Selection Filters
