# 🤖 AI Generated Dashboard – Amazon Sales Dashboard

## 📌 Overview
Created an AI-generated **Amazon Sales Analytics Dashboard** in Power BI to analyze sales performance, product trends, customer behavior, and business insights through interactive and modern visualizations.

This dashboard was designed with the help of ChatGPT to transform raw e-commerce sales data into meaningful business insights using advanced reporting techniques and smart dashboard storytelling.
