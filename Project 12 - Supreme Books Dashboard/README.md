# 📚 Supreme Books Dashboard

## 📌 Overview
Created an interactive Books Analytics Dashboard in Power BI to analyze book sales, customer preferences, author performance, and publishing trends through dynamic visualizations.

The dashboard helps users and businesses gain meaningful insights into book performance, reader interests, and sales patterns for better decision-making and strategic planning.

---

## 🚀 Dashboard Highlights
- Total Sales & Revenue KPIs
- Book Category Analysis
- Author-wise Performance Insights
- Customer Purchase Trends
- Rating & Review Analysis
- Best-Selling Books Comparison
- Monthly Sales Trend Visualization

## 🎯 Purpose
The objective of this project is to transform books and sales data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze customer preferences, monitor sales performance, identify popular categories and authors, and support data-driven business decisions.
