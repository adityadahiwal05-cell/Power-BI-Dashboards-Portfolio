# 🛒 Supreme Store Sales Dashboard

## 📌 Overview
This project showcases an interactive Store Sales Dashboard created using Power BI to analyze sales performance, customer trends, profit insights, and order statistics.

The dashboard provides meaningful business insights that help understand sales growth, customer behavior, and regional performance.

---

## 🚀 Key Insights Covered
- Total Sales, Profit & Quantity Analysis
- State-wise Sales Performance
- Category & Sub-Category Analysis
- Monthly Sales & Profit Trends
- Customer Purchase Insights
- Payment Mode Analysis
- Top Performing Products
- Regional Sales Comparison

---

## 🛠 Tools & Technologies Used
- Power BI
- DAX
- Data Visualization
- Dashboard Design
- Sales Analytics

---

## 📂 Files Included
- Dashboard PDF
- Dataset Files
- Background Assets

---

## 🎯 Project Objective
The objective of this project is to transform store sales data into actionable business insights using interactive dashboards and visualization techniques.

This dashboard helps businesses track performance, identify profitable areas, and improve decision-making.

---

## 📈 Features
- Interactive Dashboard Filters
- Dynamic KPI Cards
- Sales & Profit Trend Analysis
- Customer Insights
- Product Performance Tracking
- Region-wise Sales Visualization
