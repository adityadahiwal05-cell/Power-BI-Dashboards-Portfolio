# 💼 USA Jobs & Salaries Dashboard

## 📌 Overview
Created an interactive Jobs & Salaries Analytics Dashboard in Power BI to analyze employment trends, salary insights, job categories, and workforce statistics across the USA through dynamic visualizations.

The dashboard helps users explore job market trends, compare salary distributions, and gain meaningful insights into employment patterns and workforce analytics.

---

## 🚀 Dashboard Highlights
- Total Jobs & Salary KPIs
- Job Category-wise Analysis
- State-wise Employment Insights
- Average Salary Trend Monitoring
- Experience & Salary Comparison
- Industry-wise Workforce Analysis
- Employment Growth Visualization

## 🎯 Purpose
The objective of this project is to transform jobs and salary data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze employment trends, monitor salary patterns, compare workforce statistics, and support data-driven career and business analysis.
