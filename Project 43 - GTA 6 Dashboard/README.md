# 🎮 GTA 6 Dashboard

## 📌 Overview
Created an interactive SQL-based Power BI dashboard focused on GTA 6 gaming analytics, performance analysis, trends, comparisons, and business intelligence through dynamic visualizations.

This dashboard demonstrates the use of SQL, Power BI, DAX, data modeling, and interactive visualization techniques to transform gaming-related data into meaningful analytical insights.

## 🎯 Purpose
The objective of this project is to analyze GTA 6-related data using SQL and Power BI and transform raw data into meaningful gaming analytics and visual insights.

The dashboard provides an interactive way to explore performance metrics, trends, comparisons, and other key aspects of the dataset.
