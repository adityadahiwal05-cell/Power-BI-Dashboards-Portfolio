# 🎮 Supreme Video Games Dashboard

## 📌 Overview
Created an interactive Video Games Analytics Dashboard in Power BI to analyze game sales, player trends, genre performance, platform insights, and overall gaming industry statistics through engaging visualizations.

The dashboard helps users explore gaming data, understand market trends, and gain meaningful insights into game performance and player preferences.

---

## 🚀 Dashboard Highlights
- Total Sales & Revenue KPIs
- Genre-wise Game Analysis
- Platform Performance Insights
- Player & Market Trend Analysis
- Regional Sales Comparison
- Publisher-wise Performance Tracking
- Gaming Industry Growth Visualization

## 🎯 Purpose
The objective of this project is to transform gaming and sales data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze game popularity, monitor sales trends, compare platform performance, and support data-driven decisions in the gaming industry.
