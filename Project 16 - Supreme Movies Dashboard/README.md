# 🎬 Most Profitable Supreme Movies Dashboard

## 📌 Overview
Created an interactive Movies Analytics Dashboard in Power BI to analyze movie profitability, box office performance, audience trends, and entertainment insights through engaging visualizations.

The dashboard helps users explore movie industry data, identify top-performing films, and gain meaningful insights into revenue, ratings, and profitability trends.

---

## 🚀 Dashboard Highlights
- Total Revenue & Profit KPIs
- Most Profitable Movies Analysis
- Box Office Performance Tracking
- Genre-wise Revenue Insights
- Ratings & Audience Trend Analysis
- Budget vs Profit Comparison
- Movie Industry Growth Visualization

## 🎯 Purpose
The objective of this project is to transform movie and box office data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze movie profitability, compare revenue trends, understand audience preferences, and support data-driven entertainment analysis.
