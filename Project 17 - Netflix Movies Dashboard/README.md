# 🎥 Netflix Movies & Shows Dashboard

## 📌 Overview
Created an interactive Entertainment Analytics Dashboard in Power BI to analyze Netflix movies and TV shows data, content trends, ratings, genres, and streaming insights through dynamic visualizations.

The dashboard helps users explore entertainment data, understand viewing trends, and gain meaningful insights into content performance and platform growth.

---

## 🚀 Dashboard Highlights
- Total Movies & TV Shows KPIs
- Genre-wise Content Analysis
- Ratings & Popularity Insights
- Release Year Trend Analysis
- Country-wise Content Distribution
- Movies vs TV Shows Comparison
- Streaming Content Growth Visualization

## 🎯 Purpose
The objective of this project is to transform entertainment platform data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze content trends, compare genres, monitor ratings, and understand streaming platform performance more effectively.
