# 🌍 World Happiness Dashboard

## 📌 Overview
Created an interactive World Happiness Analytics Dashboard in Power BI to analyze global happiness scores, economic indicators, social factors, and country-wise well-being trends through dynamic visualizations.

The dashboard helps users explore worldwide happiness data, compare country performance, and gain meaningful insights into factors influencing quality of life and human well-being.

---

## 🚀 Dashboard Highlights
- Global Happiness Score KPIs
- Country-wise Happiness Analysis
- GDP & Economic Factor Insights
- Health & Life Expectancy Trends
- Social Support & Freedom Analysis
- Regional Happiness Comparison
- Year-wise Happiness Trend Visualization

## 🎯 Purpose
The objective of this project is to transform global happiness and well-being data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze happiness trends, compare country performance, understand influencing factors, and support data-driven global analysis.
