# 🦠 Covid-19 Analysis Dashboard

## 📌 Overview
Created an interactive Covid-19 Analytics Dashboard in Power BI to analyze coronavirus cases, recovery trends, death statistics, vaccination insights, and global pandemic patterns through dynamic visualizations.

The dashboard helps users monitor pandemic data, understand outbreak trends, and gain meaningful insights into the impact of Covid-19 across different regions and time periods.

---

## 🚀 Dashboard Highlights
- Total Cases, Recoveries & Death KPIs
- Country-wise Covid-19 Analysis
- Active Cases Trend Monitoring
- Vaccination & Recovery Insights
- Daily & Monthly Case Analysis
- Mortality & Recovery Rate Comparison
- Global Pandemic Trend Visualization

## 🎯 Purpose
The objective of this project is to transform Covid-19 and healthcare data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze pandemic trends, monitor recovery and vaccination progress, compare country-wise statistics, and support data-driven healthcare analysis.
