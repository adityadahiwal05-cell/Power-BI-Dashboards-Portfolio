# 🛵 Zepto Dashboard

## 📌 Overview
Created an interactive SQL-based Power BI dashboard focused on Zepto business analytics, sales performance, product analysis, customer insights, and category-wise performance through dynamic visualizations.

This dashboard demonstrates the use of SQL, Power BI, DAX, data modeling, and interactive visualization techniques to transform raw quick-commerce data into meaningful business insights.

- Product Performance Analysis

The objective of this project is to analyze Zepto business data using SQL and Power BI and transform raw data into meaningful business insights.
