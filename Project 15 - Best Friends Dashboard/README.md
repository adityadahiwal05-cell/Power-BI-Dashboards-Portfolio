# 👬 Best Friends Dashboard

## 📌 Overview
Created an interactive Social Analytics Dashboard in Power BI to analyze friendship trends, communication patterns, engagement insights, and relationship statistics through dynamic visualizations.

The dashboard helps users explore social interaction data, understand connection patterns, and gain meaningful insights into friendship activities and engagement trends.

---

## 🚀 Dashboard Highlights
- Friendship & Engagement KPIs
- Communication Trend Analysis
- Activity & Interaction Insights
- Connection Growth Monitoring
- User Participation Analysis
- Relationship Trend Visualization
- Social Engagement Comparison

## 🎯 Purpose
The objective of this project is to transform social interaction data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze engagement patterns, monitor interaction trends, understand user connections, and support data-driven social analysis.
