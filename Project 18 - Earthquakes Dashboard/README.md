# 🌍 Earthquakes Dashboard

## 📌 Overview
Created an interactive Earthquake Analytics Dashboard in Power BI to analyze earthquake occurrences, magnitude trends, affected regions, and seismic activity insights through dynamic visualizations.

The dashboard helps users explore earthquake data, monitor seismic patterns, and gain meaningful insights into natural disaster trends and geographical impact analysis.

---

## 🚀 Dashboard Highlights
- Total Earthquake Events KPIs
- Magnitude-wise Earthquake Analysis
- Region-wise Seismic Activity Tracking
- Yearly & Monthly Trend Analysis
- Depth & Intensity Insights
- Affected Area Visualization
- Global Earthquake Distribution Mapping

## 🎯 Purpose
The objective of this project is to transform earthquake and seismic activity data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze earthquake trends, monitor affected regions, understand seismic patterns, and support data-driven geographical analysis.
