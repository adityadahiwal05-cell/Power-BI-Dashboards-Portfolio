# 💳 Credit Card Customer & Transactions Dashboard

## 📌 Overview
Created an interactive Credit Card Customer & Transactions Dashboard in Power BI to analyze customer profiles, transaction trends, spending behavior, revenue insights, and banking performance through dynamic visualizations.

The dashboard helps financial institutions monitor customer activity, track transaction performance, and gain meaningful insights for data-driven decision-making.

---

## 📑 Dashboard Pages Explanation

### 👥 Slide 1 – Credit Card Customer Dashboard
The first dashboard slide focuses on customer demographics, spending patterns, and customer segmentation analysis. It provides a detailed overview of customer behavior and financial engagement through interactive visuals.

#### 🔹 Key Insights Covered
- Total Customers Analysis
- Customer Income & Spending Insights
- Gender & Age Group Distribution
- Customer Segmentation Analysis
- Credit Card Usage Patterns
- Customer Revenue Contribution

This slide helps banks and financial institutions understand customer behavior, identify valuable customer groups, and improve customer relationship strategies.

---

### 💳 Slide 2 – Credit Card Transactions Dashboard
The second dashboard slide focuses on transaction monitoring, payment trends, and financial performance analysis. It helps track transaction activity and banking KPIs using interactive visualizations.

#### 🔹 Key Insights Covered
- Total Transaction Volume Analysis
- Revenue & Profit Monitoring
- Transaction Type Distribution
- Monthly Transaction Trends
- Card Category Performance
- Payment & Spending Insights

This slide helps analyze transaction behavior, monitor financial trends, improve banking performance, and support data-driven financial analysis.
