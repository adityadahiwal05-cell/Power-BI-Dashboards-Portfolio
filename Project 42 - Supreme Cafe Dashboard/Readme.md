# ☕ Supreme Cafe Dashboard

## 📌 Overview
Created an interactive SQL-based Power BI dashboard focused on cafe sales analytics, customer insights, product performance, and store-level business analysis through dynamic visualizations.

This dashboard demonstrates the use of SQL, Power BI, DAX, data modeling, and interactive visualization techniques to transform raw cafe sales data into meaningful business insights.

---

## 📊 Dashboard Highlights
- Total Sales & Revenue Analysis
- Total Orders & Quantity Tracking
- Customer Performance Analysis
- Beverage Category Analysis
- Store Performance Comparison
- Top 5 Beverage Analysis
- Sales Trend Analysis
- Interactive Filters & Slicers
- Dynamic KPI Monitoring

## 🎯 Purpose
The objective of this project is to analyze cafe sales data using SQL and Power BI and convert raw transactional data into meaningful business insights.

The dashboard helps understand sales performance, customer behavior, beverage categories, store performance, and overall cafe business trends.
