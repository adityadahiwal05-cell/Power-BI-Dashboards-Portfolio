# 💼 Supreme Empire Pvt. Ltd. Job Hiring Process Analysis Dashboard

## 📌 Overview
Created an interactive Hiring Process Analytics Dashboard in Power BI to analyze recruitment performance, candidate trends, hiring efficiency, and overall recruitment insights through dynamic visualizations.

The dashboard helps organizations streamline the hiring process, monitor recruitment KPIs, and make data-driven decisions for better talent acquisition and workforce planning.

---

## 🚀 Dashboard Highlights
- Total Applicants & Hiring KPIs
- Recruitment Funnel Analysis
- Department-wise Hiring Insights
- Candidate Selection Trends
- Interview & Hiring Status Tracking
- Job Role-wise Recruitment Analysis
- Monthly Hiring Performance Trends

## 🎯 Purpose
The objective of this project is to transform recruitment and hiring data into meaningful business insights using interactive dashboards and analytical reporting techniques.

This dashboard helps HR teams track recruitment performance, analyze candidate trends, optimize hiring strategies, and improve decision-making in the recruitment process.
