# 💼 Supreme Company Salary Dashboard

## 📌 Overview
Created an interactive Salary Analytics Dashboard in Power BI to analyze employee salaries, compensation trends, department-wise salary distribution, and workforce insights through dynamic visualizations.

The dashboard helps organizations monitor salary structures, compare employee compensation, and make data-driven decisions for workforce planning and financial management.

---

## 🚀 Dashboard Highlights
- Employee Salary & Compensation KPIs
- Department-wise Salary Analysis
- Average Salary Trend Monitoring
- Job Role Salary Comparison
- Gender & Experience Insights
- Workforce Distribution Analysis
- Salary Growth Visualization

## 🎯 Purpose
The objective of this project is to transform employee salary and workforce data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps organizations analyze compensation trends, monitor salary distribution, compare workforce metrics, and support data-driven HR and financial decision-making.
