# 🚗 TATA EV Cars Dashboard

## 📌 Overview
Created an interactive SQL-based Power BI dashboard focused on TATA electric vehicle sales analytics, model performance, customer segments, regional distribution, and year-wise business insights through dynamic visualizations.

This dashboard demonstrates the use of SQL, Power BI, DAX, data modeling, and interactive visualization techniques to transform raw EV data into meaningful business insights.

---

## 📊 Dashboard Highlights
- Overall EV Sales & Revenue Analysis
- Total Orders & Sales Tracking
- Model-wise EV Performance
- Customer Segment Analysis
- State-wise EV Sales Distribution
- Year-wise Sales Analysis
- Regional Performance Analysis
- Interactive Model Selection
- Dynamic KPI Monitoring

## 🎯 Purpose
The objective of this project is to analyze TATA electric vehicle data using SQL and Power BI and transform raw data into meaningful business insights.

The dashboard helps explore EV sales performance, model trends, customer segments, regional distribution, and year-wise performance through interactive visualizations.
