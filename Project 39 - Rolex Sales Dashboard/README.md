# 🤖 AI Generated Dashboard – Rolex Sales Dashboard

## 📌 Overview
Created an AI-generated **Rolex Sales Analytics Dashboard** in Power BI to analyze luxury watch sales performance, regional demand, product trends, and business growth through premium and interactive visualizations.

This dashboard was designed with the help of ChatGPT to transform raw luxury retail sales data into meaningful business insights using advanced reporting techniques and modern dashboard storytelling.
