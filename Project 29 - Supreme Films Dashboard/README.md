# 🎬 Highest Grossing Supreme Films Dashboard

## 📌 Overview
Created an interactive Movies Analytics Dashboard in Power BI to analyze highest grossing films, box office collections, audience trends, and entertainment industry insights through dynamic visualizations.

The dashboard helps users explore movie performance data, compare revenue trends, and gain meaningful insights into top-performing films and industry growth patterns.

---

## 🚀 Dashboard Highlights
- Total Revenue & Box Office KPIs
- Highest Grossing Films Analysis
- Genre-wise Revenue Comparison
- Budget vs Earnings Insights
- Audience Ratings & Popularity Trends
- Movie Performance Tracking
- Entertainment Industry Growth Visualization

## 🎯 Purpose
The objective of this project is to transform movie and box office data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze revenue trends, identify top-performing films, compare movie profitability, and support data-driven entertainment analysis.
