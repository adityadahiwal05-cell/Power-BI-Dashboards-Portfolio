# 🧑‍🤝‍🧑 Customer Personality Analysis Dashboard

## 📌 Overview
Created an interactive Customer Personality Analysis Dashboard in Power BI to analyze customer behavior, purchasing patterns, demographics, and campaign performance through dynamic visualizations.

The dashboard helps users explore customer segmentation, identify spending trends, compare customer categories, and gain meaningful business insights for data-driven decision-making.

---

## 🚀 Dashboard Highlights
- Total Customers & Revenue KPIs  
- Customer Demographics Analysis  
- Spending Pattern Insights  
- Campaign Performance Monitoring  
- Customer Segmentation Visualization  
- Income & Purchase Analysis  
- Product Category Performance Tracking

## 🎯 Purpose
The objective of this project is to transform customer personality and purchasing data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze customer behavior, monitor campaign effectiveness, identify high-value customers, and support strategic business decisions.
