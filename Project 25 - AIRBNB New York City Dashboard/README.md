# 🏠 AIRBNB New York City Dashboard

## 📌 Overview
Created an interactive Airbnb Analytics Dashboard in Power BI to analyze listing trends, pricing insights, host performance, and neighborhood-wise Airbnb statistics across New York City through dynamic visualizations.

The dashboard helps users explore Airbnb market trends, compare pricing distributions, and gain meaningful insights into property performance and booking analytics.

---

## 🚀 Dashboard Highlights
- Total Listings & Revenue KPIs  
- Neighborhood-wise Airbnb Analysis  
- Room Type Distribution Insights  
- Average Price Trend Monitoring  
- Host Performance Comparison  
- Availability & Booking Analysis  
- Property Review & Rating Visualization

## 🎯 Purpose
The objective of this project is to transform Airbnb listing and pricing data into meaningful insights using interactive dashboards and analytical reporting techniques.

This dashboard helps analyze property trends, monitor pricing patterns, compare neighborhood performance, and support data-driven business and travel decisions.
